How to use it. Pick a key. With Play tonic first on, you hear the key's home chord before every question, so you are training relative pitch — recognising a note by how it sits against the key, not by memorising absolute frequencies. Start with Notes in one key, then Chords, then Find it — same sound, but you answer by tapping the fret you think it came from (any spot with the same pitch counts) — then switch keys. Chromatic mode drops the key context entirely. Keys 1–7 answer, Space plays/advances, R replays the key.

Every sound is synthesised in your browser with the Karplus-Strong plucked-string algorithm — no recordings, no server, nothing leaves the page.
